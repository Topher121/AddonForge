Discover addons

A better setup starts with the right addons.

Have a GitHub link?

Works for any addon whose author publishes GitHub releases, listed here or not.

Missing an addon? The catalogue is a public list on GitHub. Anyone can add an entry with a pull request, and AddonForge downloads straight from the author's own releases.

JUST THE WAY YOU PLAY

Settings

Your installation, addon sources and preferences.

WoW install

The product folder AddonForge manages. Only WoW: Forever is supported for now.

Updates

Some addons only ship their Forever build as a GitHub pre-release or a Wago beta. Turn this on to see and install those. Uses the GitHub API for the check, which is limited to 60 requests an hour without a token.

Wago Addons key optional

Some addons only publish on Wago. Wago's API needs a key, which is free: get one here, paste it below. It is stored on this PC and only ever sent to addons.wago.io.

Your addon list

Export the list of what you have installed (names and sources, no settings) to share with a friend or move to another PC. Import one to install everything on it.

Report a problem

Something broke? This builds a report with your version, install folder, addon list and the last few log lines. Nothing is sent until you press send in your browser or email app, and you can read it all first.
